# SHADOW OSINT — стартовый проект Telegram Mini App

Это рабочий каркас: Telegram-бот открывает веб-приложение внутри Telegram. Интерфейс чёрно-белый.

## Что уже реализовано
- Username: ссылки на публичные профили и варианты написания ника (не подтверждает наличие аккаунта).
- Email: синтаксис и публичные MX-записи домена.
- Phone: нормализация формата номера.
- IP: приблизительная публичная геоинформация.
- Domain: DNS A/AAAA/MX/NS/TXT.
- Photo Metadata: EXIF, модель камеры, дата и GPS-теги, если они остались в файле.

## Чего пока нет
- Настоящего глобального поиска по утечкам: для этого нужен отдельный легальный API и ключ.
- Обратного поиска изображений по всему интернету: нужен внешний поисковый API.
- Автоматического подтверждения похожих аккаунтов: варианты ников — только подсказки.
- Гарантированного бесплатного хостинга 24/7: условия бесплатных тарифов меняются.

## Запуск для разработки
1. Установите Python 3.11+.
2. Создайте бота через официальный `@BotFather` командой `/newbot`.
3. Скопируйте `.env.example` в `.env`, вставьте токен.
4. Для локальной проверки временно задайте `REQUIRE_TELEGRAM_AUTH=false`.
5. Выполните:
   `pip install -r requirements.txt`
6. Запустите API:
   `uvicorn main:app --host 0.0.0.0 --port 8000`
7. В другом терминале запустите Telegram-бота:
   `python bot.py`

## Публикация в Telegram
Telegram Mini Apps требуют HTTPS-домен. Разместите FastAPI-приложение на хостинге с HTTPS, задайте `WEBAPP_URL` в `.env`, а `REQUIRE_TELEGRAM_AUTH=true`. Бот и API должны работать постоянно. Не публикуйте `.env` и токен.

## Важно
Проверка Telegram initData реализована на сервере. Не отключайте её в публичном развертывании. Не собирайте пароли, не пытайтесь получить закрытые данные и не используйте инструмент для установления личности по фотографии.
